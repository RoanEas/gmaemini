========================================================================
🚀 GMAEMINI DEPLOYMENT GUIDE (สำหรับติดตั้งบน Ubuntu Server / Linux)
========================================================================

ไฟล์และโฟลเดอร์ในนี้ได้รับการคัดกรองสำหรับนำไปติดตั้งบนเซิร์ฟเวอร์ Ubuntu (Nginx / Apache + MySQL) เรียบร้อยแล้ว (ไม่รวมไฟล์ส่วนเกินขนาดใหญ่ เช่น cloudflared.exe)

------------------------------------------------------------------------
📋 1. การนำเข้าฐานข้อมูล (Database Import)
------------------------------------------------------------------------
1. สร้างฐานข้อมูลใหม่ใน MySQL/MariaDB ของคุณ (ตัวอย่างชื่อฐานข้อมูล: game_db)
2. นำเข้าไฟล์ SQL สำรองข้อมูลที่เตรียมไว้ให้ในโฟลเดอร์นี้:
   คำสั่ง CLI:
   mysql -u [USERNAME] -p [DATABASE_NAME] < "game_db.sql"
   
   (หรือนำเข้าผ่าน phpMyAdmin โดยกดที่เมนู Import แล้วเลือกไฟล์ "game_db.sql")

------------------------------------------------------------------------
⚙️ 2. กำหนดค่าการเชื่อมต่อฐานข้อมูล (Database Connection)
------------------------------------------------------------------------
เปิดแก้ไขไฟล์ `db.php` บนเซิร์ฟเวอร์ และปรับปรุงข้อมูลการเชื่อมต่อตามค่าจริงของคุณ:

```php
$servername = "localhost";
$username = "ชื่อผู้ใช้_mysql";
$password = "รหัสผ่าน_mysql";
$dbname = "game_db"; // ชื่อฐานข้อมูลที่นำเข้าในขั้นตอนแรก
```

------------------------------------------------------------------------
📂 3. การกำหนดสิทธิ์เข้าถึงไฟล์ (File Permissions)
------------------------------------------------------------------------
เพื่อให้ระบบสามารถเข้าถึง อ่าน เขียน หรือทำงานได้อย่างถูกต้อง ให้ตั้งค่าสิทธิ์โฟลเดอร์บน Ubuntu:

```bash
# เปลี่ยนเจ้าของโฟลเดอร์ให้เป็นของผู้ใช้เว็บเซิร์ฟเวอร์ (Nginx: www-data, Apache: www-data หรือ apache)
sudo chown -R www-data:www-data /var/www/html/gmaemini

# ตั้งสิทธิ์การอ่านเขียนไฟล์พื้นฐาน
sudo find /var/www/html/gmaemini -type d -exec chmod 755 {} \;
sudo find /var/www/html/gmaemini -type f -exec chmod 644 {} \;
```

------------------------------------------------------------------------
🖥️ 4. ตัวอย่างการตั้งค่า Nginx Virtual Host (ถ้าใช้ Nginx)
------------------------------------------------------------------------
หากใช้ Nginx เป็นเว็บเซิร์ฟเวอร์ สามารถใช้การตั้งค่าบล็อกเซิร์ฟเวอร์ดังนี้เพื่อรองรับ PHP:

```nginx
server {
    listen 80;
    server_name your_domain_or_ip;
    root /var/www/html/gmaemini;

    index index.php index.html index.htm;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location ~ \.php$ {
        include snippets/fastcgi-php.conf;
        fastcgi_pass unix:/var/run/php/php8.1-fpm.sock; # ตรวจสอบเวอร์ชัน PHP fpm ของคุณให้ถูกต้อง
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
        include fastcgi_params;
    }

    location ~ /\.ht {
        deny all;
    }
}
```

------------------------------------------------------------------------
🔒 5. การจำกัดสิทธิ์แอดมิน (Admin Security)
------------------------------------------------------------------------
- การแก้ไข/ CRUD คำถามในระบบ Lightning Quiz ได้รับการปกป้องโดยเซสชันแอดมิน
- หน้าที่จำกัดไว้สำหรับสิทธิ์แอดมิน ได้แก่:
  - `games/lightning_quiz/admin.php`
  - `games/lightning_quiz/index.php`
  - `games/lightning_quiz/api.php`
- ผู้ใช้ปกติจะไม่สามารถเปิดหน้าเหล่านี้ได้ (จะถูกตรวจสอบโดย `session_start()` และดีดกลับหน้าหลักหากไม่ใช่แอดมิน)
